SECTION 01

시작하기 — 로그인과 화면 소개

시스템은 인터넷 주소로 접속합니다. 별도 설치가 필요 없고, PC·태블릿·휴대폰 모두에서 열립니다.

로그인

주소 접속

브라우저에서 harimpetfood-pdlog.vercel.app 을 엽니다. 즐겨찾기에 등록해 두면 편리합니다.

이름 선택 · PIN 입력

드롭다운에서 본인 이름을 고르고, 등록된 6자리 PIN을 입력합니다. PIN은 관리자가 처음 발급합니다.

로그인 완료

로그인하면 마감 캘린더가 먼저 열립니다. 공지사항이 있으면 팝업으로 표시됩니다.

PIN 변경 — 로그인 후 화면 오른쪽 위 PIN 변경 버튼에서 본인 PIN을 바꿀 수 있습니다. 5회 틀리면 15분간 잠기며, 관리자가 잠금을 풀 수 있습니다.

화면 색상 테마

오른쪽 위 드롭다운에서 화면 색을 고를 수 있습니다. 짙은 계열(블랙·남색·차콜)과 옅은 계열(살구·크림·연녹·연파랑·회색) 중 눈이 편한 것을 선택하세요. 선택한 테마는 본인 브라우저에 저장되어, 다음에 접속해도 유지됩니다.

홈으로 돌아가기

어느 화면에 있든 왼쪽 위 홈 · 캘린더 버튼을 누르면 마감 캘린더로 돌아옵니다.

SECTION 02

메뉴 네비게이션

화면 위쪽에 있는 메뉴로 각 기능을 오갑니다. 관리자에게만 보이는 메뉴가 있습니다.

마감 캘린더

전체

월별 달력에서 팀·날짜별 마감 상태를 색으로 봅니다. 날짜를 누르면 그날의 마감 작성 화면으로 들어가고, 달력 아래 팀 카드를 누르면 월간 종합일보가 열립니다.

경영 대시보드

전체

기간·팀·완제품/반제품 기준으로 달성률·로스금액·불량·비가동을 그래프로 봅니다. 생산·원가를 한눈에 파악하는 화면입니다.

팀별 현황

전체

팀 카드를 누르면 그 팀의 생산경영현황(계획대비·가동률·스크랩·불량·비가동 + 오더별·제품별 상세)이 열립니다.

개선접수

전체

현장 개선 의견을 등록하고, 관리자가 답변·처리 상태를 관리합니다.

호기 밸런스

전체

호기(설비)별 생산 배분 현황을 확인합니다.

계획 업로드

관리자

생산 계획 데이터를 붙여넣어 등록합니다. 일자·팀·공정 조합 단위로 기존 계획을 교체합니다.

설정

관리자

사용자 관리, 결재라인 구성, 공지사항, CAPA(생산능력) 관리를 합니다.

관리자 메뉴 — 계획 업로드와 설정은 관리자로 로그인했을 때만 보입니다. 일반 담당자에게는 나타나지 않습니다.
SECTION 03

일일 생산마감 작성 방법

캘린더에서 날짜를 누르면 마감 작성 화면이 열립니다. 위쪽 요약 카드부터 아래 6개 구역까지 순서대로 확인·입력합니다.

상단 요약 카드

화면 맨 위에 그날의 핵심 숫자가 자동으로 표시됩니다. 계획을 업로드하면 계산되며, 직접 입력하지 않습니다.

작성 구역 (순서대로)

① 라인별 가동 요약

라인(공정)별 오더수·계획·실적·달성률·스크랩이 자동 집계됩니다. 확인용입니다.

② 로스(편차) 관리

계획과 실적의 편차가 있는 자재가 나열됩니다. 각 항목에 로스유형을 고르고 사유를 적은 뒤 저장합니다. 편차가 손실이면 빨강, 절감이면 초록으로 표시됩니다.

③ 불량 등록

라인·제품·불량유형·수량·사유를 입력하고 등록합니다. 여러 건 추가할 수 있습니다.

④ 비가동 등록

+비가동 등록을 누르면 아래에 입력 폼이 열립니다. 라인·구분(계획정지/비계획정지/돌발정지)·사유·시작·종료 시간을 넣고 저장합니다.

⑤ 라인별 비가동 요약

등록한 비가동이 라인별로 집계되어 카드로 보입니다. 확인용입니다.

⑥ 파트별 투입인원

라인(파트)별 계획인원·정규직·파견/일용 인원을 입력하고 인원 저장을 누릅니다.

저장은 구역별로 — 각 구역의 저장 버튼을 누르면 그 부분만 저장됩니다. 화면 전체를 한 번에 저장하지 않아도 되고, 저장할 때마다 새로고침 없이 반영됩니다.
임시저장과 제출 — 작성 중에는 임시저장으로 보관하고, 다 되면 제출로 결재를 올립니다. 제출하면 다음 결재자에게 넘어갑니다.
SECTION 04

결재 흐름

작성한 마감은 정해진 순서로 결재를 거칩니다. 각 단계 담당자는 승인 또는 반려할 수 있습니다.

작성→ 팀장→ 본부장→ CEO

제출하면 팀장에게 넘어가고, 각 단계에서 승인하면 다음 단계로 올라갑니다. 반려되면 작성자에게 돌아오며, 수정 후 다시 제출합니다. 결재 단계와 담당자는 관리자가 설정 → 결재라인 구성에서 정합니다.

결재 이력 — 마감 화면의 결재 이력 버튼에서 누가 언제 승인·반려했는지 기록을 볼 수 있습니다.

캘린더 상태 색상

달력의 각 항목은 진행 상태를 색으로 나타냅니다.

작성대기 작성/결재중 완료 반려

SECTION 05

분석 화면 살펴보기

쌓인 데이터는 여러 단계로 깊이 있게 볼 수 있습니다. 큰 그림에서 세부로 내려가는 구조입니다.

월간 종합일보 (캘린더 → 팀 카드)

캘린더 아래 팀 카드를 누르면 그 팀의 월간 종합일보가 열립니다. 팀 선택(전체/생산1팀/생산2팀/공통), 집계 단위(일/주/월), 완제품/반제품을 골라 달성률·로스금액 추이와 라인별 상세를 봅니다. 라인을 누르면 라인 상세로 더 내려갑니다.

팀 생산경영현황 (팀별 현황 → 팀 카드)

팀별 현황 메뉴에서 팀을 누르면 종합 분석 화면이 열립니다.

기간 조회

From~To로 기간을 정하거나, 전월/이번달/다음월 버튼으로 이동합니다.

핵심 지표

계획대비·계획가동률·비계획정지율·생산성·스크랩률·불량률을 카드로 봅니다.

경영요약 · 손실구조

어디를 개선하면 좋을지 핵심을 자동으로 요약해 줍니다.

도넛 · 라인별 성과표

스크랩·불량·비계획정지를 유형별 도넛으로, 라인별 성과를 표로 비교합니다.

오더별 · 제품별 상세

탭을 눌러 오더(제품코드)별, 제품별 상세를 봅니다. 우선순위의 전체보기를 누르면 전체 목록 드릴다운이 열립니다.

일부 숫자가 0인 이유 — 가동시간·투입인원·불량을 마감에서 입력해야 계획가동률·비계획정지율·생산성·불량률이 계산됩니다. 데이터가 쌓이면 자동으로 채워집니다.
SECTION 06

관리자 기능

관리자로 로그인하면 설정과 계획 업로드 메뉴가 보입니다.

설정

사용자 관리

담당자 등록·수정·활성/비활성, PIN 잠금 해제를 합니다.

결재라인 구성

결재 단계별 담당자를 지정합니다.

공지사항

공지를 등록하면 사용자 로그인 시 팝업으로 표시됩니다.

CAPA 관리

라인(파트)별 시간당 생산능력(kg/hour)을 입력하면, 라인·팀 상세에서 성능가동률이 계산됩니다.

계획 업로드

생산 계획 데이터를 붙여넣어 등록합니다. 등록 전 영향 범위를 확인하는 경고가 뜨며, 일자·팀·공정 조합만 골라 교체합니다.

한글 깨짐 주의 — 계획을 올릴 때는 구글시트에서 UTF-8 CSV로 바로 다운로드하세요. 엑셀을 거치면 한글이 깨질 수 있습니다.
데이터 백업 — 정기적으로 데이터를 CSV로 내려받아 보관하는 것을 권장합니다.
SECTION 07

자주 묻는 질문

PIN을 잊어버렸어요.
관리자에게 요청하면 설정 → 사용자 관리에서 잠금 해제·재발급을 해 줍니다.
저장했는데 화면에 안 보여요.
각 구역의 저장 버튼을 눌렀는지 확인하세요. 저장하면 그 부분만 바로 반영됩니다. 그래도 안 보이면 새로고침(Ctrl+Shift+R) 해 보세요.
달성률이 100%가 넘어요.
계획보다 실적이 많으면 100%를 넘습니다. 계획 대비 초과 생산을 뜻합니다.
로스금액이 +와 -로 나와요.
편차가 손실(초과 사용)이면 빨강 -, 절감이면 초록 +로 표시됩니다.
분석 화면에 0이 많아요.
가동시간·인원·불량을 마감에서 입력해야 관련 지표가 계산됩니다. 매일 기록하면 점점 채워집니다.
테마 색을 바꿨는데 다른 사람도 바뀌나요?
아니요. 테마는 본인 브라우저에만 저장되어, 각자 다른 색을 쓸 수 있습니다.
